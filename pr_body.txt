💡 **What:**
Replaced sequential `await` calls inside a `for...of` loop with concurrent execution using `Promise.allSettled` in the `performBulkDelete` function.

🎯 **Why:**
Previously, bulk deletions processed items sequentially, causing performance to degrade linearly with the number of items. For batch background jobs like bulk delete, Sanity API operations can be executed concurrently. Switching to concurrent promises provides a major and immediate, low-risk performance boost and ensures partial failure handling works seamlessly.

📊 **Measured Improvement:**
Using a standalone mock baseline benchmark script tested for 20 deletion items, we measured the following:
- **Baseline (Sequential):** ~1.007s
- **Optimized (Parallel):** ~50.88ms
- **Result:** ~95% decrease in elapsed execution time for bulk operations.
